## BW_Dice

A simple Dice Roller app for the Pimoroni Badgeware Tufty 2350.
There are two die available which can be set to different values up to 20 sides.

### Controls:
A = Roll Left Die.  
C = Roll Right Die.  
B = Roll Both Die. This will also give the total value of the Dice rolled.  

### Config Screen:
UP = To enter the Config screen.  

Each Die can be set to have a different number of sides.  
These can be 4,6,8,10,12, or 20.  
A = Change the left Die sides.  
C = Change the Right Die sides.  
B = Save changes to a state file and exit the config screen.  

The number of white circles will be shown on the display to represent the value of the die.  
A maximum of 9 circles can be displayed.
If the value of the roll is between 10 & 20, then blue rounded squares will be shown. This means the display does not match the number rolled.
